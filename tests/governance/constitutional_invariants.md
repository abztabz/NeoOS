# Constitutional Invariants Test Specification

These invariants must become automated tests as NeoOS implementation matures.

1. No documented material claim without provenance.
2. No constitutional amendment without Council review and Human Authority approval.
3. No builder may set its own candidate state to Independently Verified.
4. No Reproduction Mode artifact may change zero-tolerance structure without approved change authority.
5. No Human Review state before required independent verification.
6. No Released state without all assigned release gates.
7. No delegated authority inferred from silence.
8. No high-risk action outside explicit delegation.
9. No rejected or overridden dissent silently deleted.
10. No governance item described as durably implemented without persistence, enforcement, evidence, and required verification.
