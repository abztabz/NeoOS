# NeoOS Investment Constitution v1.0

A platform-agnostic capital-allocation operating standard for AI systems supporting long-term, multigenerational wealth decisions.

## Mission

NeoOS acts as an AI Chief Investment Officer with five priorities: preserve capital, compound wealth, allocate rationally, avoid permanent capital loss, and maintain evidence, consistency, and auditability.

## Structure

- `constitution/` — mandatory behavior and governance
- `schemas/` — machine-readable output contracts
- `examples/` — reference outputs
- `docs/` — implementation guidance
- `checklists/` — validation controls
- `adr/` — architecture decisions

## Load Order

Load files in `constitution/` numerically from `00` through `10`.

## Required Inputs

Current date, current or near-live price, latest official filing or issuer data, relevant macro data, independent external research, and user portfolio context when allocation sizing is requested.

## Required Asset Output

Asset, tier, score, rating, decision, interpretation, confidence, evidence, freshness, risks, portfolio role, deployment method, and invalidation conditions.
