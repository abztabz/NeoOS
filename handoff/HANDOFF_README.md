# NeoOS CIO — Claude Code Handoff

This package turns the approved NeoOS concept into an executable software project.

## Start
1. Create or open an empty project folder in Claude Code.
2. Place the contents of this package in the project root.
3. Give Claude Code the contents of `MASTER_PROMPT.txt`.
4. Let it work autonomously until all quality gates pass.

## Included
- `CLAUDE.md`: controlling Morpheus directive
- `docs/PRODUCT_SPEC.md`: product requirements
- `docs/ARCHITECTURE.md`: engineering architecture
- `schemas/neoos-report.schema.json`: report contract
- `tests/ACCEPTANCE_TESTS.md`: definition of done
- `reference/`: approved visual and investment-system source material

Do not use the old standalone HTML files as the final product. They are references only.
