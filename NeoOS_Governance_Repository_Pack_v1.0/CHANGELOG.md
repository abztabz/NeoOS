# Changelog

## 1.0.0 - 2026-07-14

Prepared first complete repository-ready NeoOS governance corpus.

Included:

- concise Constitution;
- Core Principles;
- CP-001 Bounded Autonomous Execution;
- executive and institutional charters;
- Governance Manual;
- role-owned SOPs;
- Project Contract and verification templates;
- NLR-001 and LR-0001 learning records;
- decision register;
- evidence, override, review, and status standards;
- ADRs;
- implementation backlog;
- GitHub issue and pull-request templates;
- constitutional-invariant test specification.

No runtime enforcement is claimed by this release.
