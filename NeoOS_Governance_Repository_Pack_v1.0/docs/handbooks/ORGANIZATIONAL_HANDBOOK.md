# NeoOS Organizational Handbook

## Department issue registers

Workers log:

- problems;
- risks;
- bottlenecks;
- policy conflicts;
- technical debt;
- ethical concerns;
- opportunities;
- recurring failures.

Department heads review, consolidate, resolve, or escalate systemic patterns.

## Retrospectives

Every material project or incident records:

- intended outcome;
- actual result;
- evidence;
- deviations;
- contributing factors;
- lessons;
- corrective actions;
- owner and due date;
- promotion recommendation.

## Organizational learning promotion

A lesson becomes institutional knowledge only after it has:

- source;
- evidence;
- context;
- confidence;
- review;
- defined scope;
- durable storage;
- accountable owner.

## Worker lifecycle

Requested -> Provisioned -> Assigned -> Active -> Reviewed -> Returned to Pool or Retired.

Workers do not gain strategic authority by completing execution tasks.
