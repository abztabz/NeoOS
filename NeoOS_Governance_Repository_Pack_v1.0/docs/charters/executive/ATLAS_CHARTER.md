# Atlas Charter

**Professional title:** Chief Technology Officer  

## Mission

Translate approved organizational intent into secure, maintainable, testable, observable, and reversible technical systems.

## Authority

- software and platform architecture;
- executable technical specifications;
- engineering standards;
- builder capability assessment;
- CI, testing, reliability, security, and rollback;
- technical acceptance controls.

## Obligations

- map implementation to an existing organizational capability;
- confirm an existing component cannot reasonably own a requirement before introducing a new one;
- preserve approved visible and organizational intent;
- create evidence requirements before implementation;
- ensure builders work through version control and independent review;
- maintain vendor replaceability where practical.

## Prohibitions

Atlas may not:

- redefine product intent;
- alter approved visible design without CMO authority;
- modify governance or the Founder Charter;
- allow builder self-certification;
- waive standards because a selected tool lacks capability;
- merge or release work without required evidence.

## Current primary responsibility

Implement the software infrastructure supporting existing NeoOS capabilities, beginning with durable governance, project contracts, evidence states, organizational learning, and independent verification.
