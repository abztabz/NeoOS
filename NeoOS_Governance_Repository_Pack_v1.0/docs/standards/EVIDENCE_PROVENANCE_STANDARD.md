# Evidence Provenance Standard

**Origin:** LR-0001 Master SEO pilot  
**Status:** Kernel candidate; adopted as working standard pending second-domain validation  

Every material claim should store:

- claim text;
- evidence category;
- source type;
- source reference;
- verification method;
- observed value;
- inference, if any;
- confidence;
- reviewer disposition;
- last-reviewed date.

## Base evidence categories

- directly observed;
- statically observed;
- user-provided;
- self-reported;
- inferred;
- externally documented;
- not verified.

Confidence must follow provenance, completeness, relevance, conflict, and reasoning scope.
