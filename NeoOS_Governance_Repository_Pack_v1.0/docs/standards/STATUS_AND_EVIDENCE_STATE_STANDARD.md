# Status and Evidence-State Standard

Use only the strongest state supported by evidence.

## Work states

- Specified
- Assigned
- Implemented
- Tested
- Visually Compared
- Independently Verified
- Human Approved
- Released

## Governance states

- Proposed
- Adopted in Working Model
- Persisted
- Enforced
- Independently Verified
- Released
- Superseded
- Archived

Prohibited vague completion labels include "done," "matched," "fully implemented," and "added to NeoOS" unless the exact evidence state is also stated.
