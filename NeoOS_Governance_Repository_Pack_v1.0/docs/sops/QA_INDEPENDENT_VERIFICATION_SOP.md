# QA Independent Verification SOP

1. Confirm independence from implementation.
2. Confirm baseline ID, version, and execution mode.
3. Execute or review all required tests.
4. Inspect every zero-tolerance requirement explicitly.
5. Record all variances and classify them.
6. Issue Pass, Conditional Pass, Fail, or Blocked by Missing Evidence.
7. Prevent failed or blocked candidates from being described as complete.
8. Archive evidence linked to the exact candidate version.
9. Reverify after material change.
