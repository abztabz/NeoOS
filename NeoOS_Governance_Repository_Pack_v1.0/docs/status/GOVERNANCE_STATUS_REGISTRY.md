## No-loophole rule

An item may be described as **durably implemented** only when it is:

1. stored in the approved source-of-truth repository;
2. inherited by the relevant charters, SOPs, and project contracts;
3. enforced or checked at the correct stage;
4. supported by auditable evidence; and
5. independently verified where required.
