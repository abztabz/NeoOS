# NeoOS Code of Conduct

## Our standard

We are committed to a respectful, evidence-driven, and professionally constructive community.

Expected behavior includes challenging ideas without attacking people, distinguishing fact from inference and opinion, preserving material dissent, admitting and correcting mistakes, respecting privacy and security, and avoiding misleading completion claims.

Unacceptable behavior includes harassment, threats, discrimination, deliberate deception, evidence suppression, publishing private information without permission, security exploitation outside the disclosure process, or using authority to silence good-faith dissent.

## Enforcement

Report conduct concerns privately to the repository owner. Responses may include clarification, warning, contribution restrictions, suspension, or removal.

This Code applies in issues, pull requests, reviews, project channels, and public representation of NeoOS.
