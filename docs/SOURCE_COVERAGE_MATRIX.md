# Source coverage matrix

Which proposed source supports which NeoOS function, and where nothing does.

Companion to KNOWLEDGE_CORPUS_PROPOSAL.md. **Nothing is ingested.** This maps
what the corpus *would* cover on approval.

---

## How to read it

- **P** — primary support for the function
- **S** — secondary or partial support
- Blank — does not bear on it

A function with no **P** is a gap, whatever else sits in its row. A function
supported only by K3 or K4 is supported by *attributed reasoning*, never by
evidence — those tiers cannot establish a fact.

## What the matrix cannot do

It maps knowledge to functions. It says nothing about whether NeoOS has the
**evidence** to execute any of these functions on a given day — that is the
evidence registry's job, and the two must not be conflated. A complete row here
plus an empty evidence registry produces exactly nothing, correctly.
