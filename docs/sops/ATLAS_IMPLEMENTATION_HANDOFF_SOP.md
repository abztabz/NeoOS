# Atlas Implementation Handoff SOP

1. Confirm the organizational capability being implemented.
2. Identify approved artifacts and versions.
3. Convert intent into component, state, data, responsive, security, and error specifications.
4. Define acceptance tests and evidence outputs.
5. Assess builder capability before assignment.
6. Configure version control, branch, rollback, and audit requirements.
7. Define independent verification before execution starts.
8. Prevent implementation decisions from altering approved visible intent.
9. Review builder evidence for technical completeness before QA.
10. Correct ambiguity through the proper authority, not builder invention.

## Required outputs

- executable specification;
- acceptance-test plan;
- builder capability assessment;
- evidence contract;
- rollback path;
- technical handoff authorization.
