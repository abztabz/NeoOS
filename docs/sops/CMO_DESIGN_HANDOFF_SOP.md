# CMO Design-Agent Handoff SOP

1. Identify approved artifact ID and version.
2. Declare execution mode.
3. Freeze brand, content, CTA hierarchy, section order, and zero-tolerance requirements.
4. Maintain a claim register.
5. Define allowed and prohibited interpretation.
6. Obtain Atlas feasibility review when needed.
7. Approve handoff only after references and constraints are complete.
8. Review independent design-verification evidence.
9. Route strategic visible changes to Human Authority.

Generic similarity is not fidelity.
