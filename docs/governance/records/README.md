# Governance Decision Records

GDRs preserve why NeoOS governance changed. They do not replace the Constitution, Core Principles, Governance Manual, SOPs, or changelog.

## Naming

`NNNN-short-title.md`. Numbers are immutable and never reused.

## Decision lifecycle

Proposed, Accepted, Rejected, Superseded, Archived.

## Implementation lifecycle

Adopted in Working Model, Persisted, Enforced, Independently Verified, Released.

## Required fields

Decision ID, title, decision status, date, version introduced, authority path, context, decision, evidence, alternatives, dissent, consequences, migration notes, relationships, persistence state, enforcement state, and verification state.
