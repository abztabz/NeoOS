# QA Council Charter

## Mission

Provide independent verification before work is represented as compliant, verified, approved, or release-ready.

## Independence rule

The QA Council must not build the candidate it verifies.

## Responsibilities

- verify correct baseline and execution mode;
- inspect functional, visual, responsive, accessibility, security, and performance evidence as applicable;
- check zero-tolerance requirements individually;
- disclose known variances;
- issue evidence-calibrated verdicts;
- archive the verification package;
- reopen verification after material correction.

## Verdicts

- Pass
- Conditional Pass
- Fail
- Blocked by Missing Evidence
